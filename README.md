# Photoshop-Plugin-NameNote 命名记事本
更便捷地为导出图片命名，或在不切换窗口的情况下拥有一个临时记事本。

## 功能

- **封印 / 解封**：锁定主输入框，防止误操作修改内容
- **分析**：将主输入框内容按行拆分，每行生成一张可编辑卡片
- **Name**：一键复制到剪贴板
- **Name_rules**：在原始文案后追加"-规范"并复制到剪贴板
- **Name_effect**：在原始文案后追加"-效果"并复制到剪贴板
- **Shape**：解析文案中的 `宽×高` 数值，在 PS 当前文档居中新建矩形形状图层
- **Send**：将当前行内容写回主输入框
- **del**：删除当前行卡片
- **高度调节器**：输入数值（px）调整主输入框高度，标签实时反馈偏移量

## 使用方法

1. 在主输入框输入文案（每行一条）
2. 点击"分析"，按行拆分生成卡片
3. 对每张卡片使用对应按钮操作

---

## 安装
方法一：下载 [cn.gapsun.hanxi.NameNote_PS.ccx](./cn.gapsun.hanxi.NameNote_PS.ccx)，双击安装（需有 Adobe Creative Cloud）
方法二：下载 file 文件夹，将文件夹放在 `C:\Program Files\Adobe\Adobe Photoshop[你的PS版本]\Plug-ins\`，重启 PS
